# NCR Restaurant Benchmark Explorer

*Explore how restaurant visibility, perceived quality and customer engagement vary across Delhi NCR.*

A small, offline research data product that accompanies the project **"Visible, Liked, or Both? Understanding Restaurant Visibility, Perceived Quality and Customer Engagement on Zomato"** (Marketing Analytics Research Project, IIT Gandhinagar). It is a **historical research benchmark** built from an undated Zomato listing snapshot. It is not a live Zomato service, it is not affiliated with Zomato, and its results are associations, not causal effects.

## Run it

```bash
cd PHASE3_STAGE2/WEBSITE
```

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in a browser. No internet connection, account, API key, CDN or backend is needed. See `Website_Usage_Guide.md` for details.


## Rebuild the data

```bash
python PHASE3_STAGE2/WEBSITE/build_website_data.py
```

The script reads only aggregated, verified results (`RESULTS/key_results.json`, `RESULTS/tables/*.csv`, `PHASE2_EXISTING/Phase2_Results.xlsx`). It never reads the raw restaurant-level CSV and estimates no model. It stops with an error if any sample size, identifier or denominator check fails.

## Sections

1. **Overview**: sample at a glance, the three outcome dimensions, why they are distinct, the publication pattern.
2. **Cities**: five city cards; city vs NCR benchmarks for 14 metrics; five-city comparison by metric; price and quadrant mix; within-city model estimates. Ghaziabad (n = 25) is flagged throughout.
3. **Localities**: the core tool. Choose an eligibility threshold (20 / 30 primary / 50), a city, then search or select a City + Locality unit. You get locality vs city vs NCR benchmarks with confidence intervals and sample sizes, a rating-vs-engagement scatter, composition charts and nine separate ranks.
4. **Performance extremes**: top vs bottom groups (three populations, never pooled), adjusted odds ratios, the four-quadrant framework (labelled an imposed median split) and rating spread by vote band.
5. **Research findings**: the three models, the Tier 2 to Tier 3 step, locality fixed effects, the direction table, hypotheses with the H1 qualification, and the table-booking specification sensitivity.
6. **Methodology**: sample construction, outcomes, models, analyses, limitations, the Stage 1 figures and data provenance.
